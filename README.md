End-to-End Test Automation Workflows with Cypress

This project demonstrates the development of a robust end-to-end automated testing framework for the OrangeHRM platform using Cypress. Built with the Page Object Model (POM) architecture, the framework ensures high code maintainability, scalability, and readability. It covers critical business workflows, including user authentication (Login) and Directory page operations, backed by comprehensive assertions and dynamic test data management.
